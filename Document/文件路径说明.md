+ **ColorMap**：颜色映射相关代码
  + ColorManager：颜色映射相关配置文件

+ Core：存放软件核心代码
  + **igwApplicationCore**：应用核心单例类，用于一些全局对象和全局函数的存放
  + igwViewManager：视图管理器

+ Document：文档
+ **Externsions**：软件的一些尝试性和拓展功能（）
  + Core：3D GS的一些尝试代码，有bug可以忽略
  + Sources：存放从ParaView和LidarView搬运过来的部分代码，目前没有使用
  + **XrInterface**：存放从ParaView编辑并修改过的OpenXR相关代码，配置好VTK OpenXR Remoting环境可以使用
+ **IO**：存放文档中数据读取相关类
  + igwIOCore：IO的核心类，单例类，用于管理多种文件读取
+ **Representation**：视图+表征+配置 框架中的**视图**与**表征类**存放目录
+ **RepresentationWidget**：视图+表征+配置 框架中的**配置类**存放目录
+ **Widget**：存放自定义小组件
  + **Resources**：资源目录
    + **Icon**：图标目录
  + **UI**：界面目录

+ ColorManager
  + ColorManager：颜色映射相关配置文件
    + ColorManager.json： 预设的颜色，为了方便使用替代为**igwTransferFunctionPresetsBuiltin.h**中的字符串

      ```json
      {
          "ColorSpace": "Diverging", //颜色空间，有许多种颜色空间
          "Name": "Cool to Warm",// 颜色映射名
          "NanColor": [
            1,
            1,
            0
          ],
          "DefaultMap": true,// 是否为默认映射，也就是下拉框可以看到的颜色
          "RGBPoints": [
            0,
            0.23137254902,
            0.298039215686,
            0.752941176471,
            0.5,
            0.865,
            0.865,
            0.865,
            1,
            0.705882352941,
            0.0156862745098,
            0.149019607843
          ]//颜色数组，归一化(标量区间为[0,1])的颜色映射，存储为[标量，R,G,B]
          // 上面的意思是 
          // 标量值 = 0 时颜色为0.23137254902,0.298039215686,0.752941176471
          // 标量值 = 0.5 时颜色为0.865,0.865,0.865,
          // 标量值 = 1 时颜色为 0.705882352941,0.0156862745098,0.149019607843
          // 正常情况下标量值范围为[a,b]，在进行颜色映射之前需要将其归一化为[0,1]
          // 或者将[0,1]的标量区间映射为[a,b]，标量值 a 的颜色对应 0 的颜色，b对应 1的颜色
        }
      
      ```

      pqPresetGroup.json：预设颜色分组，对不同的颜色类型进行分类，主要用于在igwPresetDialog对话框种进行颜色搜索。

  + igwColorMapCore.h/.cpp：颜色映射核心类,创建了igwPresetGroupsManager实例对象

  + igwColorMapEditorWidget.h/.cpp：颜色编辑组件，包含透明度和颜色编辑UI

   <img src="F:\VR_Code\iGreakWorks\iGreakWorks618\FlowViz\Document\文件路径说明.assets\image-20250507165259152.png" alt="image-20250507165259152" style="zoom: 67%;" />

  + **igwColorMapManager**.h/.cpp：单例类，主要管理程序中应用到的颜色映射,主要用于获取(return)vtkColorTransferFunction(颜色映射), vtkPiecewiseFunction(体绘制中透明度)为Representation使用。通过可以使用**igwTransferFunctionPresets**，传入预设的**配置名**创建**vtkColorTransferFunction**，也可以使用现成的json字符串创建**vtkColorTransferFunction**，核心函数为**ApplyPreset**

  + igwCoreUtilities.h/.cpp：工具类，来自paraiew，主要使用connect，将vtk事件和qt的槽连接起来

  + igwPresetDialog.h/.cpp：修改自ParaView源码，主要用于实现颜色选取的对话框，同时提供预设颜色的导入与导出，目前在代码中给隐藏了

  + igwPresetGroupsManager.h/.cpp：是一个用于管理igwPresetDialog 中显示的彩色映射预设组的对象。
    igwPresetGroupsManager 由 igwColorMapCore 创建并注册为管理器

  + igwPresetToPixMap.h/.cpp：用于将颜色预设转换为像素图，将json文件中一条条颜色映射转换为下图红框中的部分

    <img src="F:\VR_Code\iGreakWorks\iGreakWorks618\FlowViz\Document\文件路径说明.assets\image-20250507170925587.png" alt="image-20250507170925587" style="zoom: 67%;" />

  + igwTimer.h：计时器，可以忽略不计

  + igwTransferFunctionPresets.h/.cpp:单例类管理颜色，透明度预设的类，负责解析json格式的颜色映射，颜色映射名返回相应的**json字符串、或者vtk_json格式**

  + igwTransferFunctionPresetsBuiltin.h/.cpp：颜色映射字符串

  + igwTransferFunctionWidget.h/.cxx：颜色编辑小组件，下面红框部分

    <img src="F:\VR_Code\iGreakWorks\iGreakWorks618\FlowViz\Document\文件路径说明.assets\image-20250507172428496.png" alt="image-20250507172428496" style="zoom:80%;" />

  + vtkPVColorTransferControlPointsItem.h/.cxx：重载 VTK 基类以自定义 鼠标/键盘交互。在**igwTransferFunctionWidget**中使用，主要使用两个事件
