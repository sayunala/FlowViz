+ ColorManager
  + ColorManager：颜色映射相关配置文件
    + ColorManager.json： 预设的颜色，为了方便使用替代为**igwTransferFunctionPresetsBuiltin.h**中的字符串

      ```json
      {
          "ColorSpace": "Diverging", //颜色空间，有许多种颜色空间
          "Name": "Cool to Warm",// 颜色映射名
          "NanColor": [
            1,
            1,
            0
          ],
          "DefaultMap": true,// 是否为默认映射，也就是下拉框可以看到的颜色
          "RGBPoints": [
            0,
            0.23137254902,
            0.298039215686,
            0.752941176471,
            0.5,
            0.865,
            0.865,
            0.865,
            1,
            0.705882352941,
            0.0156862745098,
            0.149019607843
          ]//颜色数组，归一化(标量区间为[0,1])的颜色映射，存储为[标量，R,G,B]
          // 上面的意思是 
          // 标量值 = 0 时颜色为0.23137254902,0.298039215686,0.752941176471
          // 标量值 = 0.5 时颜色为0.865,0.865,0.865,
          // 标量值 = 1 时颜色为 0.705882352941,0.0156862745098,0.149019607843
          // 正常情况下标量值范围为[a,b]，在进行颜色映射之前需要将其归一化为[0,1]
          // 或者将[0,1]的标量区间映射为[a,b]，标量值 a 的颜色对应 0 的颜色，b对应 1的颜色
        }
      
      ```
